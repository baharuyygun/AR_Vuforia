# AR Project with Vuforia
An Augmented Reality (AR) project developed with Unity and Vuforia. This project aims to faciliate the visual scanning and siplay of 3D objects within a real-world environment via a device's camera.

## About the Project
The goal is to experience AR tehcnology via Unity. The application works by identifyiing a predetermined image and virtually dispalying an associated 3D object over the camera view.

## Technologies Used
- Unity
- Vuforia Engine
- Camo Studio (To connect iPhone camera)

## How It Works
1. Device's camera scans the environment.
2. Vuforia detects the prefined image target.
3. The application recognizes the target.
4. A virtual 3D object is displayed in relation to the detected image.
